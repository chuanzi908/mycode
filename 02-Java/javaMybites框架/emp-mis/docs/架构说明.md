# 系统架构与请求链路

## 分层结构

```
Controller  ── 接收请求、参数校验、返回 Result
    ↓
Service     ── 业务逻辑、事务边界
    ↓
Mapper      ── MyBatis-Plus BaseMapper，SQL 与分页
    ↓
Entity/DTO  ── 数据库映射与查询条件
```

横切关注点：LoginInterceptor（登录校验）、WebLogAspect（操作日志）、GlobalExceptionHandler（统一异常）。

## 一次请求的链路

```
浏览器 / ApiFox
   → Tomcat（ServletContainersInitConfig 启动 Spring 容器）
   → DispatcherServlet
   → LoginInterceptor（未登录返回 401）
   → EmpController
   → EmpService / EmpServiceImpl
   → MyBatis-Plus 分页插件（拼 LIMIT）
   → MySQL
   → Result 统一封装返回
```

## 关键配置

| 配置 | 位置 | 作用 |
|---|---|---|
| 数据源 | jdbc.properties | 驱动、URL、账号密码（本机端口 3307） |
| 分页插件 | SpringConfig | 注册 MybatisPlusInterceptor，控制台可看到 LIMIT |
| SQL 日志 | SpringConfig | logImpl = StdOutImpl，把 SQL 打到控制台 |
| 拦截白名单 | SpringMvcConfig | /auth/login、/auth/logout、/hello、/index.jsp |

## 扩展指引

- **新增业务表**：在 entity 建实体 → mapper 继承 BaseMapper → service 定义接口 → controller 暴露 REST。
- **新增拦截规则**：改 SpringMvcConfig#addInterceptors 的 excludePathPatterns。
- **切换数据库**：只改 jdbc.properties，代码无需变动。
