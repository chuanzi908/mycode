## 实现要点
**1) XML 版**——SQL 全写在 `ProductMapper.xml`，namespace 必须等于接口全限定名：
```xml
<insert id="insert" useGeneratedKeys="true" keyProperty="id">
    INSERT INTO product(name, price, stock, category)
    VALUES(#{name}, #{price}, #{stock}, #{category})
</insert>

<select id="findByKeyword" resultMap="productMap">
    SELECT * FROM product
    WHERE name LIKE CONCAT('%', #{keyword}, '%')
       OR category LIKE CONCAT('%', #{keyword}, '%')
</select>
```
**2) 注解版**——SQL 写在注解里，无需对应 XML：
```java
@Insert("INSERT INTO product(name, price, stock, category) " +
        "VALUES(#{name}, #{price}, #{stock}, #{category})")
@Options(useGeneratedKeys = true, keyProperty = "id")   // 自增主键回填
int insert(Product product);

@Select("SELECT * FROM product WHERE name LIKE CONCAT('%', #{keyword}, '%') "
      + "OR category LIKE CONCAT('%', #{keyword}, '%')")
List<Product> findByKeyword(@Param("keyword") String keyword);
```
**3) 注册 Mapper**——已在 `mybatis-config.xml` 和 `mybatis-config-annotation.xml` 的 `<mappers>` 里都加了一行：
```xml
<mapper class="com.chapter02.ProductMapperAnnotation"/>
```
（注意：有独立 XML 的接口用 `<mapper resource="…xml"/>`；纯注解接口用 `<mapper class="…"/>`。）
